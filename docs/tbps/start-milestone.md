# Start Milestone

# Goal

Prepare a milestone for implementation.

# Constraints

- Required specs must be present or explicitly marked as missing.
- Open decisions must be identified before implementation.
- Scope must be stable enough for execution.
- Implementation issues must reference the milestone.

# Non-Goals

- Expanding milestone scope
- Rewriting architecture
- Implementing unresolved specs implicitly

# Required Reading

- milestone document
- required specs
- related decisions
- relevant architecture documents
- `docs/TBPS.md`

# Process

1. Review milestone scope.
2. Check required specs.
3. Check related decisions.
4. Identify unresolved questions.
5. Create implementation issues.
6. Assign relevant TBPs to issues.
7. Confirm exit criteria are testable.

# Validation

- Milestone is implementation-ready.
- Missing specs are explicit.
- Implementation issues reference relevant specs and TBPs.
- Exit criteria are still valid.

# Authority

This document is authoritative for:
- milestone start process
- implementation-readiness validation
